# Map, OpenPath without mock data, absorbed

This effort no longer has a map of its own. On 2026-08-05 it was absorbed into
[#12, Map, OpenPath at production level](https://github.com/quanvu309/openpath/issues/12),
which covers the same ground plus copy, screens, flows, motion, backend shape, testing,
architecture and performance.

- **Old map**: [#3](https://github.com/quanvu309/openpath/issues/3), closed as a map.
- **Its eight tickets**: unchanged, re-parented under #12, keeping their numbers, bodies
  and blocking edges. Who computes the judgement, where the market evidence comes from,
  the career map, who a user is, where a user's data lives, the first empty screen, the
  people already using it, and whether the Coach reads the document.

Absorbed rather than run alongside because two maps would have competed over the same
screens: one deciding what a number means, the other deciding how it reads. One map, one
frontier.

The finding that made this map worth charting is carried into #12's Notes: **the app
displays analysis it never performs.** `readiness: 58`, every `fit` score and the strengths
prose are constants, and no action in the 26-action registry can change any of them.
