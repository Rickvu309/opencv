# Agents

A person's own agents, working through OpenCV.

## Language

**Delegate**:
A person's own agent, such as Claude Code, acting for them.
_Avoid_: agent client, integration, bot

**Agent connection**:
A person's permission for one Delegate to act.
_Avoid_: connection

**Grant**:
What one agent connection may read and change.
_Avoid_: scope, permission
