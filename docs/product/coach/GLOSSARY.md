# Coach

OpenCV's own agent and its conversations.

## Language

**Coach**:
OpenCV's agent. It works with the person's Profile, Papers, Jobs and Chats.
_Avoid_: assistant, AI, bot

**Chat**:
One conversation between a person and an agent.
_Avoid_: thread, conversation

**Turn**:
One message from the person and the Coach's reply to it.
_Avoid_: run

**Task**:
Coach work that continues after the person leaves the Chat.
_Avoid_: job, run

**Focus**:
The Paper, Job or thread a Chat is about.

**Coach mode**:
How much effort the Coach spends on a turn: Free, Light or Max. The Free plan uses Free only.
_Avoid_: plan
