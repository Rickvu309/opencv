## Parent

Spec 8: Paper Coach shell ([QVE-175](https://linear.app/quanvm/issue/QVE-175)).

## What to build

Absorb [assistant-ui](https://www.assistant-ui.com/) for the Paper `CoachFloat`, **spike-gated**. ADR-0007 precedent: `@ai-sdk/react` `useChat` was rejected for owning message state; `ExternalStoreRuntime` must prove it avoids that before anything ships.

1. **Spike first, inside this ticket:** adapter mapping `useCoachTurn` state (`messages`, `phase`, send/stop/retry) into `ExternalStoreRuntime`, nothing user-visible. **Kill criteria:** if the adapter must duplicate or fork message state, or take ownership from React Query, stop — record the verdict in the ADR-0007 paragraph and close this ticket with the float keeping the existing `ThreadView`.
2. If the spike passes: add `@assistant-ui/react` at a **pinned exact version**; absorb Thread + Composer primitives into `apps/web/src/features/coach/` (kit promotion waits for the Home-convergence follow-up).
3. Receipts (`detail` → `RichReceiptBody`) render inside assistant-ui message parts; streaming, Stop, retry, regenerate, thumbs, undo unchanged.
4. Theme with `@workspace/ui` tokens only; motion gated on `prefers-reduced-motion`.
5. User-facing vocabulary stays CONTEXT.md (Coach, Thread) — assistant-ui primitive names are implementation detail.

**Out of scope:** LangGraph, Assistant Cloud, branching, attachments, Home adoption (follow-up).

## Acceptance criteria

- [ ] Spike verdict recorded in the ADR-0007 paragraph (adopt or kill, with reason)
- [ ] If adopted: pinned `@assistant-ui/react`; `ExternalStoreRuntime` over `useCoachTurn` with React Query still owning message state; receipts, streaming, Stop, retry, regenerate, thumbs, undo all work in the float
- [ ] Kit tokens only; design-vocabulary test green; `prefers-reduced-motion` honoured
- [ ] CI green (GitHub Actions is the gate; no acceptance on Vercel previews)
