## What to build

**Floating Coach on Paper** — `apps/web/src/features/paper/coach-float.tsx` replaces the in-pane `CoachThreadPanel` mount in `paper-editor.tsx`; delete `coach-thread-panel.tsx`. The float keeps `useCoachTurn` (same `GET ?focusDocId` binding) and `CoachDock` (`showModePicker={false}`) inside it.

- **Closed:** bottom-right pill "Coach" (no Sparkles, no "AI assist"). **Default closed** on doc open.
- **Open:** fixed card `bottom-4 right-4`, width `min(24rem, calc(100vw - 2rem))`, max-height `min(32rem, 70vh)`; overlay — canvas scroll area's `clientHeight` must not change. `z-popover` token, never raw z-index.
- **Minimized:** header bar only (Thread title or doc name, restore, close).
- State persists in `localStorage` `openpath:paper:coach-float` (`"closed" | "open" | "minimized"`), per User. Closing never deletes the Thread.
- Desktop: non-modal `role="dialog"` `aria-label="Coach"`, no focus trap; Escape closes with focus returned to the pill; streaming region `aria-live="polite"`.
- Mobile (below `DESKTOP_MEDIA_QUERY`): full-height sheet with backdrop and focus trap.
- Motion: `--duration-base` / `--ease-standard` in the `coach.css` idiom; `prefers-reduced-motion` disables.

**Test churn is in-scope:** re-scope the ~9 `paper.test.tsx` Coach tests from `within(editor)` to the dialog; point the `use-coach-turn.test.ts` filesystem guard at `coach-float.tsx`.
