## Problem

Paper layout fights the document: the documents sidebar is always `w-60`; the in-pane Coach panel (Spec 7 S7.3) splits the editor vertically by design; nothing in the prompt forbids "paste it yourself" replies instead of real `paper.updateContent` edits.

## Solution

Spec 8 — four tickets. **Canonical spec:** `docs/specs/spec-8-paper-coach-shell.md`

**Blocked by:** none — every Spec 7 prerequisite (S7.2, S7.3, S7.4) is Done on `main` ([QVE-168](https://linear.app/quanvm/issue/QVE-168), PR #167).

| Ticket | Linear | Scope |
|--------|--------|-------|
| S8.1 | [QVE-176](https://linear.app/quanvm/issue/QVE-176) | Hideable documents panel |
| S8.2 | [QVE-177](https://linear.app/quanvm/issue/QVE-177) | `CoachFloat` — bottom-right overlay replaces the in-pane split |
