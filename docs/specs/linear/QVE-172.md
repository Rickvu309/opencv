## Parent

Spec 7: The Coach experience ([QVE-168](https://linear.app/quanvm/issue/QVE-168)).

## What to build

Persist **document grounding** on Threads so Home follow-ups on a Paper conversation still know which doc was open.

**Schema:** `threads.focus_doc_id` nullable UUID → `paper_docs.id`, `ON DELETE SET NULL`; index `(user_id, focus_doc_id)`.

**Domain / API:**
- `threads.create` accepts optional `focusDocId`; validates ownership.
- `ThreadListItem` / `ThreadDetail` expose `focusDocId`.
- `GET /api/threads?focusDocId=<uuid>` → latest Thread for User + doc, or null.
- Coach route: resolve `body.focusDocId ?? thread.focusDocId` after ownership checks.

**Web:**
- Remove `sessionStorage` doc→thread mapping (`paperCoachThreadStorageKey`).
- Paper binds thread on doc open via GET; create on first send with `{ title: docName, focusDocId }`.
