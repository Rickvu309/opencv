## What to build

Make Coach **edits visible and scannable**.

### Live doc sync
- When Coach mutates the **open** Paper doc, editor reloads from server (`doc.updatedAt` or explicit revision — not only `doc.id` / `revertKey`).
- Dirty local state + Coach write: honest conflict UI (Keep mine / Use Coach's version).
- Brief highlight on changed sections + scroll into view (`--duration-slow`, `prefers-reduced-motion`).

### Selection context
- Extend `coachTurnRequestSchema` with optional `selection: { text; sectionId? }` (capped length).
- Paper captures selection on send; "Rewrite selection" disabled when empty.
- Persona/tool copy: prefer editing selection when present.

### Rich receipts (graduate [QVE-152](https://linear.app/quanvm/issue/QVE-152))
- `paper.updateContent`: named headline + collapsed diff hunks (expand in place).
- `apply.moveCard`: card + from-Stage → to-Stage with stage dots.
- `paper.createDoc`: kind badge + name + Draft.
- Drop `Ran <command> —` from user-facing headlines. Failures stay one plain line.
- Remove `/prototype/coach-receipts` route after graduation.

Undo (QVE-149) must keep working.
