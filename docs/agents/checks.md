# Checks

Generated by `node scripts/list-checks.mjs` from the top-level describe or test name of each guard. A stale list fails `scripts/checks-doc.test.mjs`; rerun the script to fix it.

`push` runs on changed files at git push; every check runs in CI.

Every guard also has a row in `scripts/guard-ledger.mjs`. A row with a past mistake is proven with `node scripts/guard-ledger.mjs prove <id>`; `scripts/guard-ledger.test.mjs` fails on a guard with no row.
