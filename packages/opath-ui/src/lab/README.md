# Lab sourced galleries

Catalog of commodity primitives ported into Opath (Lab) for review. Production still composes `@/ui/*` primitives at the package root. Nothing here is a product noun; stories use generic copy.

Storybook is grouped by **what the surface is**, not by which kit it came from:

| Sidebar | What you are reviewing |
|---|---|
| `Lab/Components/*` | Buttons, forms, overlays, navigation, data, feedback, motion, media, chat |
| `Lab/Templates/*` | Auth, onboarding, dialogs, application shells, AI blocks, marketing pages |

Source folders (`beui/`, `beautiful/`, `eightstar/`, `kibo/`, `blocks-so/`, `transitions/`) stay as import provenance. Stories are generated into `catalog/` by `scripts/build-lab-catalog.py`.
