## Answer

Locked 15 Aug 2026. Spec: [Personal link](../spec.md#personal-link). Research: [hard-work-mark.md](../research/hard-work-mark.md) ([Research](bf6b2f24-6e01-4dfa-ae3b-6e0f2542f513)). You asked for a mechanism, not to pick a widget.

### The mark

| Asked | You chose |
| --- | --- |
| Shape? | **Span record.** Each published Proof is a named bar on a quiet year axis. Not a GitHub calendar. Not list-only. |
| What dates a span? | **Role · dates on the Proof** (the work’s life). Missing dates → a tick on the Publish day. Not days they typed in the space. |
| Name on the page? | **None.** “Span record” is internal. No “roadmap” label. |

### The page (advisor, from the same research)

| Topic | Lock |
| --- | --- |
| Identity | A **sentence** (name, what they’re after). Handle lives in the URL. |
| Index | Same Proofs as **dated rows**, year-grouped: dates · title · one-line why. Not cards. The span is a door to `/p/[slug]`. |
| Empty | Sentence only. No grey grid. No CTA. No shame. |
| Craft | Same family as `/p/[slug]`. Not a second (dark) site. |
| Fragment | On `/p/[slug]`: the role · dates line becomes a one-line strip (this span + faint ticks). Tap → `/u/[handle]`. Same strip may sit on the Docs space. |
| Owner | Same public page. Tools stay in Docs. |
| Game | No streak, no score, no totals in a heading, no colour intensity, no empty grid. |
