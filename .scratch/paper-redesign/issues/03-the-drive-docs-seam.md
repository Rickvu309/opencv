# The Drive–Docs seam

Type: grilling
Status: resolved

## Question

How do you move between Drive and Docs so it feels like one place, not two apps?

Keep the two modes: list first, then different chrome when a paper is open. Not editor-first. Not a Profile-style split.

Open: shared shell vs two full layouts; what stays put (rail, title, back); whether opening a row is a cut, a push, or a shared-element move; how gallery and letter chooser sit on that seam; how Application and Coach opening `/paper?id=` inherit the same arrival.

Seamless and easy is the bar. Use `/grilling`, `/domain-modeling`, `/better-layout`. Name any motion in `/animation-vocabulary` terms only — values wait for [What My Paper motion is for](10-what-my-paper-motion-is-for.md). Do not build.

## Answer

Locked 15 Aug 2026. Written into [spec.md](../spec.md) (Drive–Docs seam). Supersedes `docs/paper.md` “CV: structured fields + live A4” for *how you write* — a CV is still structured; you edit the A4, not a form that paints it.

### Round 1 — the room

| Asked | You chose |
| --- | --- |
| One shell or two pages? | **One My Paper room.** The sticky band stays. Its job changes: New + filter become Back + title + type + Export. The body changes: stack becomes the opened paper. Not two full layouts. Not a split. |
| How does a row become Docs? | **Shared element transition:** slab + name travel. The rest of Drive **Fade out**. Back is the reverse. No origin (Application / Coach) → skip the travel, land in Docs. Not a cut. Not a push. |
| Where do gallery and letter chooser sit? | **Drive modes, same room.** Band becomes Back + the question. The wall replaces the stack on the same leading edge. Picking a tile then takes the Drive → Docs seam. |
| Application or Coach opens `/paper?id=`? | **Land in Docs.** Same chrome. No Drive flash. **Back always to Drive.** Rail still has Application / Coach. |

### Round 2 — landing and create

| Asked | You chose |
| --- | --- |
| Where does the shared element land? | **Both.** Name → title. Slab → sheet. The band swaps with no second flight. |
| New paper, no row yet? | **Gallery tile is the origin.** Proof from New, or inbound from Application / Coach: no origin. |

### Round 3 — the A4 is the output

| Asked | You chose |
| --- | --- |
| Where do you write a CV? | **On the A4**, with a slim palette to add sections. Not a left-hand form that paints a preview. You work on the output — a canvas — so you can see what you are making instead of depending on formatting elsewhere. **chatPRD**-like: edit the document itself ([writing documents](https://www.chatprd.ai/docs/writing-documents)). Not chat-left / doc-right as required Docs chrome (Coach stays a quiet offer). |
| Resume.io lead on the map? | **Replaced.** Open CV joins letter and Proof dump: the page is the work. Resume.io stays a reference for “the sheet is an object,” not form-paints-preview. Ticket [Opened CV](06-opened-cv.md) retargeted. |

### Held

Uploads do not take this seam (preview is a Drive click — still fog). Motion values wait for [What My Paper motion is for](10-what-my-paper-motion-is-for.md).
