# Upload as a starting point

Type: grilling
Status: resolved
Blocked by: 04

## Question

How does the honest upload door work in Drive — tonight’s stub, and later when extract is real?

## Answer

Locked 15 Aug 2026. Spec: [Upload](../spec.md#upload).

**Tonight** is the user’s situation (I need a CV, I need it fast). Not a product mode. Fast means we drop *our* delays — extra rooms, Profile seed, fake reading. Without extract they still type. Ghost starters are how.

**Two objects.** The file stays **Uploaded**. A **built CV** is a sibling. Never merge. You cannot type in the file. OpenPath does not parse it until extract is real.

**Doors**

| Where | What happens |
| --- | --- |
| Empty Drive — **I already have a file** | CV starting-point door. File lands. Built CV opens. Skip the gallery. Unmade object is gone when they Back. |
| New → Upload | File only (CV or letter). Stay in Drive. |
| Upload row — **Start a CV from this** | Same write path as the empty door: built CV, skip the wall. Preview / download stay. |
| Onboarding drop | File only. Do not open Docs. They **Start a CV from this** when they come to My Paper. |
| Letter file | Stays **Uploaded**. Preview / send. Does not open a built letter. |

**The A4.** No Profile seed (there won’t be enough). No uploaded words (we didn’t read the file). **Plain working structure** — name, contact, employment, education, skills. Not a named situation. Ghost lines they can Tab. Format → Where it’s going is how a situation arrives (same wall, same paper). Copy tells the truth: this file is your start; you write on the paper.

**Land.** No gallery origin → skip travel, land in Docs ([Motion](../spec.md#motion)).

**When extract is real (later).** Fill *that same* built A4. Scan **Reveal** only then. No theater until words actually appear.

Supersedes [Gallery wall](05-gallery-wall.md) “after Upload, the wall comes next.” Supersedes `docs/paper.md` “click upload = preview only” for the *write doors*; the file itself is still preview / download. Glossary (`Uploaded file`) updates when this spec is accepted — starting a CV does not turn the file into a paper.
