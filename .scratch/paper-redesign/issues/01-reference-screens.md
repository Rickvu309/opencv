# Reference screens for My Paper

Type: research
Status: resolved

## Question

What do the lead products actually look like, from primary sources (the live product or its official marketing), not blog recaps?

Need three families, with URLs and a short steal / reject for each screen:

1. **Resume.io / Kickresume** — the list of CVs, the form + live A4 editor, export. What makes the sheet feel like an object?
2. **Google Docs** (or a close “page is the work” editor) — opening a doc from a list, chrome that gets out of the way, typing on the page.
3. **A personal / proof-like public page** — one project page and one index of a person’s work (not a social feed). What makes it feel considered rather than a CMS?

Also note anything that would recreate the poster-grid Drive `docs/paper.md` already rejected.

Write findings to `.scratch/paper-redesign/research/reference-screens.md`.

## Answer

Findings: [reference-screens.md](../research/reference-screens.md).

The list is a picker you leave. Resume.io is title + file actions; Kickresume is preview cards you click — that card grid, and both template walls, are the A4 poster-grid Drive already rejected. The builder is a form that paints a live A4: page arrows, spacing on the sheet, export on the object. That is what makes the sheet an object.

Google Docs leaves the list behind, hides menus in compact mode, and types on the page. Drive’s official default is a list, not a grid. Pageless is not a sendable CV.

Chimero and Rauno feel considered (title, dates, work). A project page is title, a why, then pictures. Kickresume Websites is the CMS control: one-click resume skin, section tabs, Contact Me.
