# Drive as a place you pick

Type: grilling
Status: resolved

## Question

How should Drive be laid out so it is spatial, seamless, and easy — a place you pick tonight’s paper — without becoming the A4 poster grid `docs/paper.md` rejected?

Keep: flat enough to scan (name · type word · updated), type filter, empty “Start with the CV.”, New = CV / Cover letter / Proof / Upload, uploads read Uploaded.

Open: density, grouping, what the row *is* (line, sheet edge, something else), empty-state as a space, how New sits, how this layout still works with one paper and with twelve.

Use `/grilling`, `/domain-modeling`, `/better-layout`, and `/impeccable` (layout). Do not build.

## Answer

Locked 15 Aug 2026. Written into [spec.md](../spec.md) (Drive). Product nouns stay in `docs/paper.md`.

### Round 1 — the stack

| Asked | You chose |
| --- | --- |
| What is a row? | A **sheet edge**: still a list (name · type word · updated). A leading mark like the edge of a stack. The paper is hinted, not pictured. Not a table line. Not a mini A4. |
| What is the empty Drive? | A **room with one unmade object** — tonight’s CV. Click it, gallery. Not a settings card. Not a ghost row. Not a template wall. |
| Where does New sit when there are papers? | A **control zone** (header / toolbar). Filter sits with it. Not a fake row in the list. |
| One paper vs twelve? | **Same structure, more air when the list is short.** Never a hero card. Never a different kind of object. |
| Grouping besides the type filter? | **Flat only.** Filter when more than one type is present. No type bands. No recency bands. Job grouping stays on Application. |

### Round 2 — edges and chrome

| Asked | You chose |
| --- | --- |
| Empty room → first paper? | **Same room, same leading edge.** The unmade object sits where the first row will sit. Adding a paper is a reveal, not a new layout. |
| Upload rows? | **Same structure, a quieter / different mark** — a file, not a sheet. Type word remains **Uploaded**. Not a separate band. |
| Column headers? | **Drop.** Type and updated stay on the row. The list is a stack, not a table. |
| Control zone when the list is long? | **Sticky.** New at the leading edge, filter at the trailing edge. |
| What is the sheet-edge mark? | **A thin leading slab** — the thickness of a stack. No type icon. No folded corner or page silhouette. Colour waits for [Paper craft: colour and type](04-paper-craft.md). |

### Held from earlier locks

Empty copy: “Start with the CV.” Populated New: CV, Cover letter, Proof, Upload. Duplicate / delete on the row menu. Ask Coach stays a quiet offer under the list, not in the empty room. Kickresume card grids and template walls stay rejected as Drive.
