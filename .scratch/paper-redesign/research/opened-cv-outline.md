# Opened CV — cheap artifact

Not a build. Today’s editor is a form left, A4 preview right, and on the phone an Edit | Preview switch. That is the thing we are leaving.

```
[ Back ]  Title (editable)   CV|Resume    Export
          (same sticky band)

          desk (second neutral)
          ┌─────────────────────────┐
          │  Name                   │  + Employment
          │  ────                   │  + Education
          │  Work                   │  (palette: tools,
          │  · role · org           │   not a second CV)
          │  Education              │
          │                         │
          └─────────────────────────┘
          A4 — you type here
```

You click a block and type on the paper. Ghost placeholders show what belongs there. Completeness is a quiet % in the band, not a dashboard. Format (“where it’s going”, density) lives on the desk, not as a second full-width workbench bar, and not as paint on the output.

Below `md` there is no Edit | Preview. There is only the sheet.
