## Summary

Closes #2139. The web type check skipped every test file and the shared test helpers (`apps/web/tsconfig.app.json` excluded them), so tests could call removed code or fake results the real contract rejects. On main this hid 362 type errors in 71 files. Now:

- **The check covers tests.** `apps/web/tsconfig.test.json` extends the app config and includes `src`. `apps/web/tsconfig.json` references it, so the existing `pnpm typecheck` (`tsc -b --noEmit`) and every CI job that runs it type-check tests. No workflow change.
- **Internal domain subpaths type from source.** `@workspace/domain/internal/paper-presentation` and `paper-page-scale` resolved to `packages/domain/dist`, so code and tests could compile against stale built types. `tsconfig.app.json` now maps them to source like the other domain paths.
- **Real faults the check found**, fixed at the source:
  - Job preview mocks returned shapes the contract rejects (no `fields`, `location` or `description`), and `fullPreview` papered over them. The mocks now return valid previews, and `fullPreview` is gone.

  - `setMockChats` dropped the `createdAt`/`updatedAt` that tests passed. It now keeps them.
  - The marketing link check reported failures as `link: undefined`.
  - A Coach chat test scripted a tool that does not exist (`paper.replace`).
  - `coach-draft.ts` typed a browser timer id as a Node timer.

- **Removed** two Word page test cases (Word pages are gone since #2125). Each changed or removed check is recorded in `scripts/retired/2139.json`.
