# Icons and motion

Sources, read 2026-11-13 through their `.md` copies:

- Icons, https://developer.apple.com/design/human-interface-guidelines/icons
- Motion, https://developer.apple.com/design/human-interface-guidelines/motion

The apple-design skill (`~/.claude/skills/apple-design/SKILL.md`) owns how motion should feel (springs, interruption, velocity). This file only says what a check must see.
