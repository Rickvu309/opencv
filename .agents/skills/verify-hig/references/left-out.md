# Left out, and why

OpenCV is a web app in desktop and phone browsers, not a native Apple app. These guideline rules were read and not carried over. Pages read 2026-11-13 through their `.md` copies.

| ID  | Page              | Guideline sentence (quoted)                                                                                                              | Reason                                                                                            |
| --- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| X1  | Accessibility     | "Integrate with Siri and Shortcuts to let people perform tasks using voice alone."                                                       | No web API.                                                                                       |
| X2  | Accessibility     | "Optimize your app's UI for Assistive Access."                                                                                           | iOS and iPadOS feature only.                                                                      |
| X3  | Accessibility     | "Support Switch Control."                                                                                                                | System feature; a web page gets it through keyboard support (A10).                                |
| X4  | Accessibility     | "Use haptics in addition to audio cues."                                                                                                 | The product makes no sound; browsers expose almost no haptics.                                    |
| X5  | Accessibility     | "Consider offering difficulty accommodations in games."                                                                                  | Not a game.                                                                                       |
